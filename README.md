## Про репозиторій

Цей репозиторій створений для виконання навчальних завдань, лабораторних робіт та практичних вправ з веб технологій.

У репозиторії зберігатимуться матеріали пов'язані з навчанням

## Улюблені мови програмування

Мої основні мови програмування:

- **C++** — основна мова для вивчення програмування та об'єктно-орієнтованого програмування.
- **C#** — використовую для розробки ігор та роботи з Unity.
- **GDScript** — використовую під час роботи з ігровим рушієм Godot.

## Технології та інструменти

У навчанні та власних проєктах використовую:

- **Git** — система контролю версій.
- **GitHub** — для зберігання та керування репозиторіями.
- **Visual Studio** — середовище розробки C++ та C# проєктів.
- **Unity** — ігровий рушій для розробки 2D та 3D ігор.
- **Godot** — ігровий рушій з підтримкою GDScript.
- **Markdown** — для оформлення документації.

## Інтереси

Основний напрям, який мене цікавить у програмуванні, — **розробка ігор**.

Особливо цікавлять:

- програмування ігрової логіки;
- розробка систем персонажів та ворогів;
- робота з ігровими рушіями;
- 2D та 3D розробка.
